# Licensing Heine and its starter material

This file identifies the intended license boundary for material in this
repository. It is practical information, not legal advice.

## Heine

Heine, including its Rust source, tests, documentation, and release material,
is licensed under EUPL-1.2-or-later unless a file declares another license.
The authoritative EUPL text is [`LICENSE`](LICENSE).

Contributors provide accepted changes under the same terms. EUPL-1.2-or-later
permits distribution under a later EUPL version, so moving to a later EUPL
version does not need a separate contributor agreement. The project does not
currently use a contributor license agreement or copyright assignment. Adopting
an unrelated license or dual-licensing contributed code would require
permission from the relevant copyright holders.

## Copyable starter material

The authored files in `starter-site/` and in the copyable `starter` kit are
licensed under MIT. This includes the reference site's content, configuration,
templates, stylesheets, scripts, and authored example assets. The MIT text is
included wherever a user receives the starter material:

- `starter-site/LICENSES/MIT.txt` for the runnable starter site;
- `starter-site/kits/starter/LICENSES/MIT.txt` for public kit files; and
- `starter-site/kits/starter/site/LICENSES/MIT.txt` for the copyable reference
  site.

Files that declare another license remain under that license. In particular,
the bundled STIX font is licensed under OFL-1.1, and the historical Heinrich
Heine portraits retain their public-domain declarations in adjacent sidecars.

## Sites built with Heine

Using Heine does not by itself license an independently authored site under
the EUPL. A site author chooses the license for that site's own content and
code. Copying material from the starter site or kit is different: that copied
material is available under the MIT terms above, while separately declared
third-party files retain their own terms.
