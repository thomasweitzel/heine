# Privacy notice

*Example text for a static site, last updated 30 August 2026.*

## This is an example, not a deployment policy

The starter site is a local demonstration. It has no contact form, account
system, analytics service, advertising network, or comment section. A real
site must replace this page with a notice that describes its actual deployment.

## An imaginary host

For illustration, imagine the site is served by **Rheinufer Hosting GmbH**,
whose servers are said to be as steady as the river and considerably less
inclined to write poetry. Like most web hosts, such a provider would normally
process request data, such as an IP address, request time, requested path,
status code, referrer, and browser information, to deliver and secure the site.

## No mystery cookies

This example does not set cookies or store data in the browser. If a real site
adds analytics, embedded media, a theme switcher, comments, or similar
features, its privacy notice must explain those choices plainly.

Questions about the fictional operator belong, fittingly, to the
[Imprint](page:imprint/index).
